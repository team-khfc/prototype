# 검증 기록 · 2026-11-04

## 통과

- Next.js 프로덕션 빌드, TypeScript 검사, 정적 내보내기.
- 핵심 로직 6개: 검토 미완료 거부/원본 보존, 오래된 수정 버전 거부, 신청자 검토 명령 거부, 필드에 연결된 보완 요청, 완료 후 수정 제한, 새 게시 버전의 신규 신청 적용.
- 실제 브라우저에서 검색 결과 12 → 1건, 협의 상세 이동.
- 내부 메모 저장 후 이력 증가, 보완 요청 등록 후 상태 변경.
- 체크리스트 3개와 검토 의견 입력 후 사전 협의 완료, 수정 버튼 비활성화.
- 관리자 질문 제목 수정 → 초안 저장 → 게시본 v2.3.0에서 v2.4.0으로 변경.
- 새 신청은 v2.4.0, 기존 신청은 v2.3.0 유지.
- ICT인프라 역할의 서버·DB/통신/운영 기간 체크리스트 표시.
- 새로고침 후 신청·의견·메모 유지, 시연 초기화로 12개 기본 신청 복원.

## 수정한 문제

- HTTP 미리보기에서 crypto.randomUUID가 제공되지 않는 문제: 시연 이력 ID를 crypto.getRandomValues 기반으로 변경.
- Next 개발 서버와 미리보기 프록시에서 화면 초기화가 완료되지 않아, 최종 검증은 실제 배포와 동일한 정적 출력물로 수행. 로컬 개발 명령은 `npm run dev:web`로 별도 제공.
- 완료한 긴급 건은 긴급 업무 필터에서 제외하고, 0건 안내 문구를 구분.

## 검증하지 않은 범위

- Java 21·Maven이 없어 Spring Boot 실행·JUnit·실제 HTTP 연동은 미실행. 이 환경은 Java 17만 제공함.
- 로그인, 서버 권한, Oracle DB, 실제 AI, 실첨부파일, 절차 엔진, 최종 제출·처리 완료는 구현 범위 밖.
- 브라우저 검증은 제공된 데스크톱 뷰포트에서 수행. 1920px 와이드 및 작은 화면의 CSS 분기는 포함했지만 모든 해상도에서의 자동 스크린샷 비교는 수행하지 않음.
- CSV 및 텍스트 다운로드·인쇄 UI는 구현했으나 모든 브라우저의 다운로드/인쇄 결과를 보증하지 않음.

이는 사용자 흐름 검증 결과이며, 운영 서비스의 보안성 검증 또는 부하 시험 결과가 아닙니다.
