# ADR 0003 — AI 연결과 비공개 컨텍스트 경계

- 상태: 이번 프로토타입에 적용
- 일자: 2026-11-06

## 결정

- 기본값은 외부 호출을 하지 않는 `EXAMPLE` 예시 추출 모드다. 실제 생성형 모델의 실행 결과라고 표시하지 않는다.
- OpenAI와 Gemma는 교체 가능한 별도 어댑터로 둔다. 연결의 제공자·모델·정확한 엔드포인트·키 참조·생성 옵션은 게시된 DB 설정으로 관리한다.
- API 키는 환경변수로만 주입한다. DB에는 허용된 키 참조 이름만 저장한다. 접속 대상은 관리자가 입력했다는 이유만으로 허용하지 않고 서버의 정확한 URL 허용 목록을 재검사한다.
- 외부 호출 실패 때 예시 결과로 대체하지 않는다. 실패한 분석 이력을 남기고 사용자가 다시 실행할 수 있도록 한다.
- 업로드는 사용자의 명시적 분석 요청 때만 수행한다. 지원 범위는 UTF-8 TXT·MD, 최대 1MiB다. 확장자·내용·경로를 검증하고 임의 식별자로 저장하며 원본을 변경하지 않는다.
- 분석에 사용한 신청 revision과 실행 당시 연결 정보를 기록한다. 수정 전 자료에서 나온 오래된 결과는 최신값으로 조용히 덮어쓰지 않는다.
- 모델 출력은 좁은 구조로 검증하고 신청서에는 미확정 후보로 반영한다. 내부 IP·서버명은 추출 대상에 포함하지 않는다.
- 기관 비공개 컨텍스트는 별도 AES-256-GCM 저장 영역에서 기관 식별자와 결합하여 암호화한다. 공개 지식 근거와 혼합하거나 자동으로 외부 모델에 전달하지 않는다.

## 검증 구분

어댑터 계약 테스트는 요청 형식·응답 파싱·실패·출력 검증을 확인한다. 실제 외부 두 모델의 생성 품질과 접근 권한을 입증하려면 승인된 환경에서 API 키를 주입하여 별도의 실호출 평가가 필요하다. API 키가 없는 상태의 계약 검사를 ‘두 모델 실구동 완료’로 표시하지 않는다.
