# 이번 새 프로토타입 검증 기록

검증일: 2026-11-06. 이 기록은 `security-advisor-design-prototype` 소스에 대해 이번 작업에서 실제 실행한 결과다. 이전 생성물의 검사 결과는 포함하지 않는다.

백엔드의 79개는 **실제 PostgreSQL을 사용한 외부 검증 DB 모드**의 결과다. H2나 저장소 대역으로 대체하지 않았다. 다만 Docker/Testcontainers 경로를 통과했다는 의미는 아니다. 기본 테스트 설정은 Docker가 있는 환경에서 Testcontainers를 요구하도록 유지했다.

## 실제 HTTP로 확인한 업무

1. 실제 합성 계정 로그인, 세션, CSRF 거절, 역할별 접근 경계.
2. **방화벽 신청:** 생성 → 예시 분석 → 저장된 AI 후보 적용 → 사람이 확인하면서 AI 원출처 유지 → 협의 → 전문 정보·통신 입력 → 보완 답변·담당자 해결 → 양쪽 검토 → 멱등 제출 → 접수.
3. **보안성검토 신청:** 생성 → 역할별 필수 답변 확인 → 협의 → 보완 → 검토 → 최종 제출·접수.
4. 기관 설정 초안 저장, 게시 재전송 멱등성, 기존 신청의 정책 버전·본문 유지.
5. 기관 컨텍스트 저장과 일반 사용자 접근 거절.
6. 로그아웃 후 이전 세션으로 업무에 접근할 수 없는지 확인.

두 서류 흐름에서는 같은 기관의 다른 작성자와 다른 기관의 조회·문서 다운로드를 거절했고, 오래된 revision에 409와 최신 버전을 반환했다. 미완성 제출과 제출 후 변경도 거절했다. 접수 전후 다운로드 문서의 해시가 같음을 확인했다.

추가로 최초 합성 신청 12건, 런타임 DB 계정의 DDL 거절, 기관 컨텍스트의 암호문 저장을 확인했다. 서버를 정상 종료·재시작한 뒤 신청 수와 기존 제출 문서가 보존되고 시연 자료가 중복 생성되지 않는 것도 확인했다.

## 백엔드 검사에서 확인한 주요 실패 경로

- 기관·작성자·역할 위반, 일반 사용자의 통신 입력, 관리자 업무 접근.
- 동시 수정 두 요청 중 한 건의 충돌 및 변경 유실 방지.
- 누락·null revision, 누락된 멱등 헤더·분석 파라미터의 400 응답.
- 미확정 AI 제안, 근거 누락, 잘 모름, 미해결 보완, 무효화된 검토의 제출 차단.
- 실제 게시된 순차 정책에서 정보보안 → ICT인프라 순서 강제 및 변경 후 재검토.
- 제출 스냅샷·게시 이력의 DB 수정/삭제 거절.
- 컨텍스트 암호문 변조와 기관·자료 식별자 바꿔치기 거절.
- 업로드 확장자·UTF-8·크기·읽기 전용 원본 보관.
- 허용하지 않은 모델 필드·기술 주소·원문에 없는 근거·중복 후보 거절.
- 두 외부 모델의 요청·응답 형식을 **HTTP 전송 대역**으로 확인. 실제 외부 생성 호출로 계산하지 않음.

## 브라우저 확인

데스크톱 브라우저에서 동일한 React 표시 컴포넌트를 사용하는 다음 공개 시안을 열어 확인했다.

- 대시보드: 헤더·왼쪽 메뉴·네 상태 카드·우선 확인 목록·진행 안내.
- 협의 요청함: 표·필터·페이지 이동, 검색어 입력 시 1건으로 좁혀지고 초기화 시 복귀.
- 정보보안·ICT인프라 검토: 본문과 오른쪽 검토 패널, 통신 표, 출처와 사람 확인, 미확정 표시.
- AI 분석: 예시 모드·원문 근거·후보 적용과 확정의 구별, 업로드/변경 비활성.
- 기관 설정: 질문 목록과 편집 영역, 초안·게시본 버전, 변경/게시 비활성.

문서 미리보기 대화상자의 초기 포커스, Escape 닫기, 원래 버튼으로 포커스 복귀를 확인했다. 마지막으로 합성 시안의 제출 준비·제출 완료 행에 두 검토가 완료로 표시되고, 작성 중 행은 검토 대기, 보완 행은 재확인 필요로 표시되는지 확인했다.

브라우저에서는 공개 시안만 확인했으며 실제 계정 입력·제출 흐름은 위 HTTP 검사로 확인했다. 반응형 CSS와 표 내부 스크롤은 포함했지만 **모바일·좁은 뷰포트·스크린리더 전수검사와 접근성 인증은 하지 않았다.**

## 검증 중 발견하여 수정한 사항

- Spring Boot 4의 Flyway 자동 구성에 필요한 starter 의존성.
- 최초 응답과 DB 재조회 사이 시각 정밀도 차이: PostgreSQL microsecond 정밀도로 기록.
- 프런트와 Compose의 API 프록시 환경변수 이름.
- 원본 시안과 다른 순차 검토 순서.
- 수정하지 않은 메모리 초안이 이전 revision을 유지하던 불필요한 충돌.
- 필수 헤더/파라미터 누락의 오류 계약, 질문 키·입력 길이·모델 옵션 상한.
- 업무 단계와 모순되던 합성 시안의 검토·보완 상태.

각 수정 후 해당 검사와 최종 빌드를 실행했다. 테스트의 업무 기대값을 낮추거나 검사를 비활성화하여 통과시키지 않았다. 순차 검토 테스트는 지정 원본 시안의 명시적 순서에 맞춰 구현과 계약을 함께 정정했다.

## 남은 검증·구현 범위

실제 OpenAI/Gemma 생성 품질과 두 모델 실구동 입증, 공개 문서 본문 RAG, PDF/DOCX/HWP 입력·전용 양식, 운영 SSO·계정 관리·분산 세션, 실제 방화벽 장비 적용은 완료 범위가 아니다. Docker 이미지 빌드와 Compose 전체 기동은 Docker가 허용된 환경에서 다시 확인해야 한다.
