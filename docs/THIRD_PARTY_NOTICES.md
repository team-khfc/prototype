# 외부 자산과 기준

사용자가 지정한 [prototype-soo](https://github.com/team-khfc/prototype-soo)의 디자인·토큰·글꼴·아이콘 체계를 참고했다. 공급 라이선스는 현재 사용 자산과 함께 보존한다.

- Pretendard GOV: `frontend/public/assets/vendor/krds/Pretendard-LICENSE.txt`.
- Lucide 기반 SVG 아이콘: `frontend/public/assets/vendor/Lucide-LICENSE.txt`(ISC).
- KRDS 공급 토큰: `frontend/public/assets/vendor/krds/css/token/krds_tokens.css`. 프로젝트 별칭은 frontend/styles에서 관리한다.

이번 시안 커밋·규칙·차이는 [SOURCE_REFERENCES.md](SOURCE_REFERENCES.md)에 있다. 라이선스의 저작자 표기는 권리 고지이며 합성 업무 자료의 실존 개인정보 사용을 의미하지 않는다. 패키지 버전은 프런트 lock 파일·Gradle 설정을 따른다. KRDS 인증이나 접근성 인증을 획득했다고 표시하지 않는다.
