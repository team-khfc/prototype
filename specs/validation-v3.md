- 공식 토큰 파일과 실제 400/700 WOFF2 사용. 공식 CSS 파일 자체는 변경하지 않음.

## 중요한 제한

운영 서버·AI·인증·권한·DB·실제 파일 처리·기관 양식 생성은 연결하지 않았다. 기존 Spring Boot v1 샘플은 v3와 연결되어 있지 않으며 Java 실행 검증을 새로 수행하지 않았다. 기관 설정의 조건부 질문 엔진과 다양한 입력 유형은 아직 공통 텍스트 입력으로 표현한다. 실제 운영의 보안정보를 sessionStorage에 저장하는 방식으로 사용하지 말 것.

세션 만료 화면 및 오류 주입은 화면 체험이다. 지원하지 않는 선명한 화면 모드, 공식 인증, 전체 가이드 준수를 주장하지 않는다. 자동 검사 숫자는 서버 보안 검증이나 실제 AI 평가의 개수가 아니다.
