# Third-party resources

KRDS design tokens and Pretendard GOV static fonts copied from the existing project's pinned krds-uiux@1.1.0 resource set. Token source: https://github.com/KRDS-uiux/krds-uiux . Official token CSS is unmodified. The project consumes semantic aliases in app/globals.css.

Pretendard GOV Regular (400) and Bold (700) are loaded from local WOFF2 files; font license: public/vendor/krds/Pretendard-LICENSE.txt . Lucide React icons follow the project's existing locked dependency.

These resource versions are separate from the 2025.08 PDF guideline version. Project custom controls use these tokens and React behavior, not the KRDS DOM-manipulation JavaScript. Button/field height is 48 CSS px at the default text scale. The 1920 px shell and 240 px sidebar are project extensions.
