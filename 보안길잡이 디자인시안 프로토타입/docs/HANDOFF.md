# 보안길잡이 디자이너 작업본 — 개발 인계

2026-11-06. 이 패키지는 지정된 디자인 시안을 수정·검토하기 위한 HTML 작업본이다. 실제 인증·AI 호출·저장·제출·기관 전송과 업무 상태 엔진을 포함하지 않는다. 합성 데이터만 사용한다.

## 시작 위치

- [작업 가이드](DESIGN_GUIDE.html): 편집·내보내기·새 화면 만들기·인계 방법.
- [Foundations](../foundations/index.html): 색상·타이포·간격·레이아웃.
- [Components](../16-components.html): 공통 UI와 상태 비교.
- [Patterns](../patterns/index.html): AI 미확정·실패·오래된 결과·권한·충돌·세션·버전·제출 확인·빈 목록.
- [화면 목록](../index.html): 역할별 대표 업무 화면 15개.
- [새 화면 템플릿](../templates/blank-screen.html): 같은 폴더에서 복제하여 사용.

## 편집 결과의 구분

| 파일·기능         | 담는 내용                   | 인계 시 확인                                        |
| ----------------- | --------------------------- | --------------------------------------------------- |
| HTML 내려받기     | 현재 화면의 문구·토큰·폼 값 | 원래 상대 폴더 위치와 공통 assets 폴더 유지         |
| 변경본 백업       | 화면별 JSON                 | 같은 data-screen 식별자의 화면에서 복원             |
| 토큰 CSS 내려받기 | 현재 토큰 변경값            | 검토 후 assets/css/design-overrides.css에 수동 반영 |
| 단독 시안         | CSS·폰트를 포함한 정적 HTML | 공유·검토용. 편집 도구·화면 이동·업무 동작 없음     |

내보내기는 원본 파일을 자동 덮어쓰거나 서버에 저장하는 기능이 아니다. 수정 전에 원본을 보관하고 내려받은 파일을 다시 열어 결과를 확인한다. 공통 CSS를 변경해도 각 화면의 개별 변경값이나 Figma 파일이 자동으로 동기화되지는 않는다.

단독 시안은 내장 기본 CSS·글꼴과 현재 문구·입력값·지원 토큰을 담는다. 외부 CSS 파일을 직접 수정한 레이아웃·새 규칙은 자동으로 묶지 않으므로, 해당 변경은 HTML과 assets 폴더를 포함한 전체 패키지로 인계한다.

## 개발자가 유지할 업무 의미

- AI는 제안하며 사람의 확인과 원출처를 구분한다. 출처가 없으면 담당자 확인 필요다.
- 파일 선택, 분석 요청, 후보 적용, 사람 확인, 최종 제출은 다른 행동이다.
- 정보보안·ICT인프라 순차 검토는 정보보안 완료 후 ICT인프라 검토다.
- 보완이나 중요 정보 변경 뒤 기존 검토의 유효성을 다시 판단한다.
- 검토 완료·제출 완료·서류 접수·실제 처리는 서로 다른 상태다.
- 기관 설정의 초안 저장은 게시가 아니다. 새 게시본이 기존 신청을 자동 변경하지 않는다.
- 권한·기관 범위·업무 전이·버전 검증은 서버가 최종 판단한다.

## 구현에 반영하는 방법

HTML의 마크업·토큰·상태를 해당 React 공통 컴포넌트와 화면에 반영한다. 디자인용 JavaScript를 인증이나 업무 상태 엔진으로 사용하지 않는다. 렌더링되는 문구와 함께 label/for/id, ARIA 연결, 키보드·초점·반응형을 보존한다.

기본 프레임은 1920×1080, 업무 셸 최대 1920px, 왼쪽 메뉴 240px이다. 1920px는 최소 너비가 아니며 화면 높이를 고정하지 않는다. 제목·본문·표가 긴 경우와 좁은 화면·확대 상태를 별도로 확인한다.

공식 토큰 CSS와 공급 폰트·라이선스는 보존한다. 공통 변경은 design-overrides.css, 추가 화면 보완은 screen-patches.css로 관리한다. 이 작업본은 프로젝트 규칙 원문이나 접근성·KRDS·보안 인증을 대체하지 않는다. 이전 프로토타입의 테스트 결과를 이 파일들의 검증 결과로 승계하지 않는다.
