클라우드 Chrome, 기본 화면 너비 1348px. 전용 로컬 정적 미리보기에서 검증.

- 안내 페이지와 업무 요약, 원본과 일치하는 기본 색상·글꼴·셸 확인.

- 요청함에서 “재난” 검색 → 1건 확인.
- 역할 전환 → 신청자 사업 정보 화면 이동 확인.

- Enter로 미리보기 → Escape로 닫기 → 원래 버튼에 초점 복귀 확인.

## 제한

- 실제 모바일 기기, Safari/Firefox, 스크린리더 및 모든 화면의 모든 상태는 검증하지 않음.
- `file://` 실행은 상대 경로·일반 script 사용 구조로 지원하며 이번 브라우저 검증은 HTTP 정적 미리보기에서 수행.
- TXT 다운로드 파일의 바이트 비교 검사는 미실행.
- 원본의 서버·업무 전이 테스트를 이 정적 편집본의 기능으로 간주하지 않음.
- HTML 샘플의 모든 버튼이 운영 기능을 수행하는 것은 아님. 동작 범위는 README.md 참조.
- 공식 접근성 인증이나 KRDS 전체 준수 판정이 아님.
