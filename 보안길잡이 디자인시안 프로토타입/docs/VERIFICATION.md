# 디자이너 작업본 검증 기록

검증일: 2026-11-06. 대상: 이 패키지의 HTML 화면·편집 도구·내보내기 기능.

이 기록은 이번 작업에서 실제 실행한 검사와 관찰만 정리한다. 기존 서비스의 프런트엔드·백엔드 테스트 결과를 이 작업본의 결과로 사용하지 않았다.

구조·상호작용·내보내기 자동 검사는 Node.js/JSDOM 환경에서 수행했다. 폰트·실제 화면 배치는 아래 브라우저 관찰과 구분한다. 이러한 검사는 보안 취약점 진단이나 전체 접근성 인증을 의미하지 않는다.

### 화면 상호작용 7개 그룹

1. 01~16 화면 초기화, 중복 ID, 주 제목과 본문 영역.
2. 목록 검색·초기화·상태 선택·페이지·행 선택, 문구 편집 중 업무 동작 방지.
3. AI 제안의 출처 유지와 미확정 상태, 선택한 파일명의 평문 표시.
4. 제출 준비 화면의 상태 일관성, 상태 예시 모달과 닫은 뒤 초점 복귀.
5. 관리자 문서 검색과 결과가 없는 상태.
6. 질문 설정의 메모리 내 초안·검색·텍스트 질문 범위.
7. 정보보안 검토 다음 ICT인프라 검토 순서.

### 편집·내보내기 5개 그룹

1. JSON 백업에서 문구·폼·토큰 복원. HTML처럼 보이는 문구도 평문으로 유지.
2. 다른 화면의 백업, 알 수 없는 문구·필드 식별자, 허용되지 않는 CSS, 과도한 문구 거절. 거절 시 기존 편집 유지.
3. 편집 HTML을 다시 열었을 때 값과 백업 호환성 보존. 단독 시안의 CSS·글꼴 내장, 외부 참조와 편집 도구 제거.
4. 표 행 순서 변경 후 HTML을 다시 열어도 같은 화면의 JSON 백업 복원.
5. 하위 폴더에 있는 템플릿의 상대 자산 경로와 화면 식별자 보존.

파일 다운로드·대화상자 등 브라우저 전용 기능은 자동 검사에서 필요한 부분을 대체했다. 실제 브라우저의 HTML 내려받기 완료는 별도로 확인했다.

추가로 공통 CSS를 교체한 뒤 읽힌 초기 토큰을 모의하여, 단독 시안에 현재 토큰·본문 크기·패널 간격이 포함되는지 확인했다. 기존 화면별 토큰 style이 있는 경우와 없는 경우 모두 확인했으며, 내보내기로 원본 문서의 style을 바꾸거나 style을 중복 추가하지 않았다. 이 추가 보완은 JSDOM에서 검증했고 브라우저에서는 재실행하지 않았다.

## 실제 브라우저에서 확인한 항목

데스크톱 Chrome의 로컬 HTTP 미리보기에서 다음을 직접 확인했다.

- 화면 목록의 실제 화면 축소 미리보기와 검색. 특정 화면 검색 시 1/15, 초기화 시 15/15 표시.
- 기본 정보 화면의 입력값 변경과 글자 수 표시 갱신.
- 문구 편집 모드에서 제목 수정, 편집 종료.
- 디자인 토큰 대화상자에서 색상 변경과 참고 대비 값 갱신.
- 토큰 대화상자의 첫 입력 필드 초점, Escape로 닫기, 도구 버튼으로 초점 복귀.
- HTML 내려받기 버튼을 통한 실제 다운로드 완료.
- 컴포넌트 가이드의 색상·글꼴·오류·빈 상태·간격 예시 배치.

이 과정에서 동적 글자 수 표시, 문구 편집 래퍼와 기존 스타일의 충돌, 표 순서 변경 시 백업 식별, 토큰 대화상자 초점 순서, 간격 예시의 중복 문구를 수정했다.

## 검증하지 않은 범위

- Windows/macOS의 모든 브라우저와 `file://` 실행 정책 조합. 로컬 파일 실행을 위한 상대 경로로 구성했으나 각 환경의 직접 열기까지 검증한 것은 아니다.
- 모바일·태블릿 전체 화면, 모든 확대 비율, 스크린리더 전체 흐름, KRDS 전체 준수 또는 접근성 인증.
- Figma 네이티브 파일 생성, 자동 동기화, HTML 가져오기 플러그인의 레이어·컴포넌트 변환 품질.
- 실제 로그인·권한·기관 격리·업무 전이·버전 검증, AI 호출, 업로드 문서 분석, DB 저장, 실제 제출·전송.
- 다중 사용자 공동 편집, 자동 클라우드 저장, 원본 파일 자동 덮어쓰기.
- 외부 CSS를 직접 수정했을 때 단독 시안에 해당 규칙을 자동으로 묶는 기능. 단독 시안은 내장 기본 CSS·글꼴과 현재 문구·입력값·지원 토큰을 대상으로 한다. 직접 수정한 외부 CSS는 전체 폴더로 전달한다.

디자인을 제품에 반영할 때는 위 미검증 범위를 별도로 확인한다. 참고용 대비 값은 표시된 두 색상 조합만 계산하며 전체 화면의 접근성 판정을 제공하지 않는다.
