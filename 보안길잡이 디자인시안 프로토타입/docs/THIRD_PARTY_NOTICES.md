- Pretendard GOV: 동봉한 `assets/vendor/krds/Pretendard-LICENSE.txt` 참조. 폰트 원본을 보존했습니다.
- Lucide React 1.31.0에서 렌더링한 인라인 SVG 아이콘: `assets/vendor/Lucide-LICENSE.txt`(ISC) 참조. React 런타임을 배포하지 않고 SVG 마크업만 포함합니다.
