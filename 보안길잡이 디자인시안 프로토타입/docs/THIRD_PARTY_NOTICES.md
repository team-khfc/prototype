# 외부 자산과 라이선스

사용자 지정 `team-khfc/prototype` 디자인 시안의 자산을 재사용했다.

- Pretendard GOV Regular/Bold: `../assets/vendor/krds/Pretendard-LICENSE.txt`의 SIL Open Font License. 글꼴 파일을 수정하지 않았다.
- Lucide 기반 인라인 SVG: `../assets/vendor/Lucide-LICENSE.txt`의 ISC 라이선스. 화면의 SVG 마크업과 고지를 함께 보존했다.
- KRDS 디자인 토큰: `../assets/vendor/krds/css/token/krds_tokens.css`는 공급 원본을 유지한다. 프로젝트별 변경은 `design-overrides.css`에서 한다. 공식 자료: https://www.krds.go.kr/html/site/index.html
- 공통 화면·CSS: 사용자가 지정한 보안길잡이 디자인 시안.
- 추가한 편집 도구는 별도 외부 라이브러리나 CDN 스크립트를 요구하지 않는다.

라이선스 원문에 나오는 저작자 정보는 권리 고지이며 시연 사용자나 업무 데이터가 아니다. 이 패키지는 KRDS 전체 준수 또는 접근성 인증 결과를 의미하지 않는다.
