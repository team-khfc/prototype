디자인 작업본Foundations

일관된 화면을 만드는 기준

색상·글꼴·간격·레이아웃을 공통 토큰으로 관리합니다.

기준값과 현재 시안은 구분합니다.

아래 숫자와 색상 코드는 원본 기준값입니다. 색상 견본은 현재 적용된 토큰을 보여 줍니다. 변경안은 대비·반응형 확인 후 인계해 주세요.

01 / COLOR

역할이 있는 색상

의미별 별칭인 --sf-*를 사용합니다. 색상만으로 상태를 구분하지 않고 문구와 표식을 함께 제공합니다.

주요 행동--sf-primary원본 기준 #256EF4
강조 텍스트--sf-primary-text원본 기준 #0B50D0
선택·정보 배경--sf-primary-soft원본 기준 #ECF2FE
기본 본문--sf-text원본 기준 #1E2124
보조 설명--sf-muted원본 기준 #464C53
패널 경계--sf-border원본 기준 #CDD1D5
기본 바탕--sf-surface원본 기준 #FFFFFF
업무 배경--sf-background원본 기준 #F4F5F6
보조 강조--sf-secondary원본 기준 #063A74
해당 작업 완료--sf-success원본 기준 #267337
보완·확인 필요--sf-warning원본 기준 #8A5C00
오류--sf-danger원본 기준 #BD2C0F
검토 중담당자 확인 필요검토 완료입력 오류

초록색 ‘검토 완료’는 보안 적합 판정이나 실제 방화벽 적용 완료를 뜻하지 않습니다.

일반 텍스트 대비 4.5:1 이상, 큰 텍스트 3:1 이상을 확인합니다. 본문은 7:1 이상을 설계 목표로 둡니다. 팔레트만 보고 검증 통과로 처리하지 않습니다.

AI 제안의 원문 근거를 확인하고 필요한 내용을 담당자와 함께 보완합니다.

도움말·보조 정보 · 15px · 400

확인할 수 없는 정보는 ‘담당자 확인 필요’로 남겨 주세요.

위 예시는 글자 크기 비교용이며 제목 태그를 중복하지 않습니다. 실제 화면에는 대표 h1 하나를 두고 정보 위계에 맞는 제목 태그를 사용합니다.

04 / LAYOUT

넓은 업무 화면, 유연한 본문

1920×1080은 기본 설계 프레임입니다. 페이지의 최소 너비나 고정 높이가 아닙니다.

화면 영역별 배치 계약
영역 기본 PC 작은 화면·확대
업무 셸 최대 1920px, 중앙 정렬 본문 한 열, 페이지 전체 가로 넘침 방지
왼쪽 메뉴 240px 접힌 메뉴에서도 같은 화면에 접근
본문 좌우 여백 일반 40px / 넓은 화면 48px 중간 화면 24px / 작은 화면 16px
검토 상세 본문 + 340px 이상 검토 패널 패널을 본문 아래로 배치
장문 입력 약 880px 이내를 우선 레이블·도움말·오류를 같은 흐름에서 표시
데이터 표 내용에 맞는 열 너비 표 영역만 가로 스크롤

최상위 강조 버튼은 업무 페이지 전체에서 1개 이하입니다. 현재 작성 단계의 필수 입력은 탭이나 접힌 영역 안에 숨기지 않습니다.

05 / TOKEN HANDOFF

공통 변경값을 전달하는 방법

편집 도구의 ‘디자인 토큰’에서 변경안을 확인한 뒤 ‘토큰 CSS 내려받기’를 사용합니다. 내려받은 값을 검토하여 assets/css/design-overrides.css에 적용하면 이 파일을 참조하는 화면에 함께 반영됩니다.

원본 파일은 자동으로 덮어쓰지 않습니다. 화면별 변경안과 공통 변경안을 구분하고, 색상 변경 시 실제 전경·배경·초점 상태를 다시 확인합니다.
