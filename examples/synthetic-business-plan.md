# 공개 안내 챗봇 합성 사업개요서

이 파일은 프로토타입 시연 전용 합성 자료입니다. 실제 기관, 사람, 내부 IP, 서버 자산과 비공개 규정은 포함하지 않습니다.

사업 목적: 공개된 연금제도 안내를 쉽게 찾을 수 있는 가상 챗봇을 준비합니다.
이용 대상: 합성 질문으로 안내 내용을 확인하는 가상 이용자
처리 정보: 공개 안내 문서와 합성 질문만 사용하며 실제 개인정보는 사용하지 않습니다.
외부 전송: NO
운영 기간: 2026-11-06부터 2026-12-06까지 합성 시연
데이터 흐름: 합성 질문 입력 → 공개 안내 검색 → 원문 근거를 포함한 안내 답변

## 담당자와 함께 확인할 사항

운영 환경, 통신 규칙, 접근 통제와 기록 관리는 전문 담당자가 합성 시연 구성을 확인하여 별도로 입력합니다. 이 문서에서 기술 자산 정보를 추정하거나 확정하지 않습니다.

외부 전송의 NO는 예시 추출 모드에서 사용하는 ‘아니요’ 값입니다. 실제 입력 화면은 예·아니요·잘 모름으로 표시합니다. 이 파일을 분석해도 답변은 미확정 후보이며 사람이 확인해야 합니다.
